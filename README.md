# Sagala Venkata Krishna — Advanced Portfolio

A responsive dark-tech portfolio made with HTML, CSS, and vanilla JavaScript.

## Included features
- Cinematic hero section with CSS-built laptop / AI illustration (no college photo)
- Circular animated scroll-down cue
- Line-by-line reveal animations as sections enter the viewport
- Top reading-progress bar
- Right-side circular section navigation on desktop
- Active section indicator in the navigation
- Responsive mobile navigation
- Project, skills, experience, achievements, and contact sections
- Back-to-top button
- Contact form that prepares an email draft using `mailto:`

## Files
- `index.html` — portfolio content
- `styles.css` — styling and responsive layout
- `script.js` — interactions and scroll animations

## Open locally
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html`.
4. For a local server, install the **Live Server** extension, right-click `index.html`, and choose **Open with Live Server**.

## Before publishing
- Verify all personal, project, achievement, and internship details.
- Replace general GitHub repository links on each project card with the exact project URL when available.
- Add a real resume PDF if you want a resume-download button.
- The contact form opens the visitor's email application; it does not send messages through a website backend.
